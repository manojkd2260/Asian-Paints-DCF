# Asian Paints DCF Valuation & Comparable Company Analysis

## Overview
This repository contains a Discounted Cash Flow (DCF) valuation model and Comparable Company Analysis for Asian Paints.

## Features
- Historical financial analysis
- Revenue and expense forecasting
- FCFF valuation
- WACC calculation
- Terminal value estimation
- Enterprise & Equity Value
- Comparable Company Analysis
